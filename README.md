# Expense Tracker
A simple and efficient command-line Expense Tracker built using Python.  
This project helps users manage daily expenses by adding, viewing, deleting, and categorizing expenses through a menu-driven interface.
# Features
- Add new expenses
- View all expenses
- Delete expenses by index
- Categorize expenses
- Store expense details using Python dictionaries and lists
- Simple menu-driven interface
- Beginner-friendly project structure
# Technologies Used
- Python 3
# Python Concepts Used
- Functions
- Lists
- Dictionaries
- Loops
- Conditional Statements
- User Input Handling
- CRUD Operations
